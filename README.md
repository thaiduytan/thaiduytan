## ✦ About

Full-stack developer and QA engineer. I work on both sides of the same problem:
I design and ship web products end to end (React, Node.js, PostgreSQL, Docker),
then try to break them before anyone else can.

Writing the code and testing it myself means I build with failure modes in mind
and fix with evidence, not assumptions.

## ✦ The Ultima code

```text
1. Reproduce first, fix second.   Every bug gets a failing test before it gets a patch.
2. Test where it hurts.           Real servers, real networks, real failure modes.
3. Ship with proof.               Small PRs, clear evidence of what changed and why.
```
